# Issue #15 평가·체결 시점 후속 제안

팀 검토 초안. [평가 프로토콜](evaluation-protocol.md)의 15:30 규칙은 이번 PR에서 유지한다. 보존 ALFRED 연구본은 KRX 참조 종가 후 30분인 16:00 또는 17:00을 평가 시각으로 사용해 가격 복구 효과를 비교했다. 첫 발표의 실제 가용 시각이나 해당 가격에 대한 체결 가능성은 확인되지 않았다. 이번 검토에서 Test 날짜의 커버리지는 확인했고 Test 성과 계산과 모델 선택은 수행하지 않았다.

## 대안

| 대안 | 필요한 증빙과 적용 방식 |
| --- | --- |
| 15:30 유지, 먼저 검토 | 15:30까지 검증된 국내 직전 세션 종가 또는 시각이 증명된 장중 관측을 사용한다. 해외 종가는 기존 1세션 래그를 적용한다. 같은 마감가로 의사결정과 체결을 모두 가정하지 않도록 최초 검증 가능한 후속 체결 시각을 정의한다. |
| 장 마감 이후 결정, 별도 정책 PR | 공급자 공개 기록을 확보해 종가를 실제 확인할 수 있는 결정 시각을 정한다. 다음 거래 가능 시점에 체결하며 특수 거래일도 명시한다. 기존 16:00·17:00 연구 가정을 실제 공개시각으로 간주할 근거는 아직 없다. |

## 검증 기준

- `reference_at`, 실제 공개시각, 연구 가정, `decision_at`, `execution_at` 및 보상 시작·종료 시점을 따로 기록한다. 해당 결정에서 사용한 관측과 환율은 결정 시각까지 가용해야 한다. 장 마감 이후에 사용 가능해진 값을 같은 마감가로 체결한 결과에 사용하지 않는다.
- 한·미 휴장, 조기 종료, 수능일과 뉴욕 서머타임을 날짜별로 테스트한다. ALFRED 빈티지 데이터는 주간 H.10 공개 일정과 날짜별 수정 이력을 구분한다. ALFRED 14일 가정은 근거와 허용 범위를 별도 검토하며, 기존 7일 기본값을 일괄 변경하지 않는다.
- 공식 원천으로 시각을 재현한 후 새 데이터 및 계보를 해시로 고정한다. 시간 경계·분할·비용·보상 검증을 통과해야 변환을 검토한다. 환율 자료 및 결합 데이터의 학습 이용 권한은 별도로 확인한다. 원천 자료의 불확실성은 #138의 승인 발급 검토에 남긴다.

15:30 정책 수치를 변경하는 경우 #125의 변경 절차에 따라 별도 PR을 작성한다. 사유와 Test 성과 열람 여부를 명시하고 팀원 전원의 승인을 받는다. 이미 Test 성과를 본 뒤 바뀐 정책은 기존 본 결과를 대체하지 않고 함께 보고한다. [평가 프로토콜 변경 절차](evaluation-protocol.md#9-변경-절차)

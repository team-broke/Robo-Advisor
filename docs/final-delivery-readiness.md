## 과제 원문과 병합된 정책의 차이

- **Sharpe 기준**은 과제 PDF 11쪽에서 PPO − 동일가중 ≥ +0.2이고, #125에서는 PPO − 시장 합성 벤치마크 ≥ +0.2다. 같은 날짜·비용의 결과표에 두 차이를 다른 열로 보고한다. 누적수익률 +10%p 기준은 양쪽 모두 시장 벤치마크 대비다.
- **가격**은 PDF 3쪽에서 수정주가를 요구한다. #125는 KOSPI·S&P 500 합성에 PR 지수를 지정하고 ETF 수익률 기준이 같은지 함께 보고하도록 한다. yfinance의 조정 OHLC에는 배당·분할이 반영될 수 있으므로 학습과 비교가 각각 어떤 가격인지 명시하고, 배당 포함 ETF 수익과 PR 비교를 자동으로 같은 기준으로 인증하지 않는다.
- **결측**은 PDF 3쪽이 Forward Fill 후 잔여 결측 제거를 요구한다. #125는 공통 평가 날짜 제외와 가격 보간 금지를 규정한다. 학습 전처리에 허용한 제한적 과거값 유지, 실제 평가에서의 공통 제외, 보유 장부의 손익을 분리해 기록한다. 기준이 불일치하면 변경 전에 팀과 합의한다.
- **월간 시점**은 PDF 4쪽과 #125에서 월 첫 거래일을 언급한다. 현재 비교 코드는 월 첫 평가일에 끝나는 전이를 기준으로 **전월 마지막 공통 평가 세션**에서 장부 리밸런싱을 적용한다. 실제 체결 규정과의 해석 차이는 실험 결과 공개 전에 팀에서 확인한다. [현재 구현의 장부 시점](integrated-backtest.md#월간-리밸런싱과-수익률-종료일)
- **첫 평가일**을 포함하는 #125의 관측 문맥과 현재 PPO 진단의 종료일 기준 lookback 요구는 통합 실행 전 확인한다. 첫날을 누락하거나 Test에 맞춰 λ·FX 나이·결측 정책을 선택하지 않는다.

## 전달 스냅샷 오류 우선순위

기존 로컬 `team-snapshot-audit-20261126` 결과를 재사용했다. 전달본은 33개 payload가 일치했고 품질 `failed` 5종·`unverified` 11종, 실제 공개 시각 확인 0/16개였다. 데이터셋에 실제 런 입력이 있었다는 근거는 없으며 이번 판정의 `training_approved=false`를 유지한다.

| 분류 | 기존 감사에서 확인한 내용과 할 일 |
|---|---|
| **A — 실제 입력 차단** | Yahoo USD/KRW는 192개 OHLC 위반일 모두 `Close`가 범위 밖이다. 보존 연구 기간까지 156일, 2026년에 36일이다. 이 FX를 그대로 사용하면 USD 자산 원화 가격과 로그·단순수익률, RSI·MACD까지 영향이 전달될 수 있다. 실제 사용 입력의 해시·날짜·가용시각·검증 기록이 연결되지 않거나 필수 결측·불연속이 남으면 승인 보류다. |
| **B — 연구 조건으로 검토** | EFA 2일과 DBC 1일의 조정 `Close` 범위 이탈은 1 ULP라 수익률·지표에 대한 직접 수치 영향은 기계 정밀도 수준이다. 수치 잡음 분류는 연구 후보며 원본, 오류 이력, 최종 승인 상태를 보존한다. ALFRED 14일 가정과 SMBS 7일, 이전 KRX 세션 또는 17:00 정책은 가용 시각과 체결을 분리하고 선택 사유를 고정한 후 비교 후보로 쓸 수 있다. 신규 입력의 허용 여부는 팀이 결정한다. |
| **C — 현재 Close 기반 경로에 직접 영향이 없는 항목** | KTB10Y 2020-03-10 위반은 Open < Low로 해당 행의 Close 범위 위반은 없다. 이 조건 자체가 Close 수익률·RSI·MACD를 바꾸지는 않으나, 수집기 실패와 원천 증빙 문제는 유지한다. DGS3MO 79일 결측은 #125의 무위험수익률 0, 현재 현금 수익률 0 경로에 직접 입력되지 않는다. 금리를 쓰는 별도 비교라면 검사가 필요하다. |
| **D — 정식 금융 검증에서 해결** | 전체 거래일의 가격 공개 로그, 장 마감 후 실제 주문·체결 증빙, 전체 조정계수·배당·분할 독립 인증과 가격 제공자 교차 검증은 정식 적용 전에 필요하다. 과제 연구의 사용 근거와 제한을 명시하고 실제로 없는 증빙에는 미확인 상태를 부여한다. |

S&P 500의 2019-12-31 종가는 전달본에서 확인했다. KOSPI 2일 및 국내 ETF별 26일 누락은 남아 있다.
벤치마크 날짜가 빠졌으면 완전한 시장 상대 성과로 보고할 수 없다. 현금과 자산 보유가 유지되는 동안의 손익은

## 실제 학습 자료 수령 뒤에 진행할 작업

1. 같은 run ID의 원본 완료 manifest, 실제 설정, 입력 Parquet와 해시, checkpoint와 당시 해시, Monitor·학습곡선, 평가 일정·벤치마크 및 RiskTag 파일을 받는다. #134로 사전 검사·전달 검증을 실행해 사후 패키지 해시와 학습 시점 증빙을 구분한다.
2. 실제 스텝 수, seed, 승인 범위, Train/Validation/Test 경계, 정규화 범위, 누락과 연속 구간, 태그 가용 시각과 ETF 매핑을 확인한다. 모델·입력 불일치가 있으면 해당 런의 성과 비교를 보류한다.
3. #130으로 Train의 참고 지표, Validation 모델 선택, Test 성과, 현금·집중도·Safe-Guard를 각각 확인한다. #133으로 PPO·MVO·동일가중·시장 벤치마크를 같은 날짜·비용·시작 상태에서 비교하고 두 Sharpe 기준을 동시에 표시한다.
4. 선택된 모델의 SHAP Summary/Force Plot을 생성하고, 완주한 보상×seed×창 결과로 ANOVA 3종 표본을 구성한다. 이어서 승인된 산출물의 API 로더와 Streamlit 표시를 확인하고 README·최종 PDF를 완성한다.

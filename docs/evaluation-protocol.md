# 평가 프로토콜

백테스트·통계 검증의 판정 규칙을 결과를 보기 전에 고정한다. 아래 값은 테스트 구간 결과를
본 뒤 바꾸지 않는다. 변경 절차는 마지막 절을 따른다.

## 1. 공통 평가 조건

| 항목 | 값 |
| --- | --- |
| 데이터 범위 | 2020-01-01 00:00 ~ 2026-01-01 00:00 (Asia/Seoul, 끝 배타) |
| 평가 시각 | 매 공통 거래일 15:30 Asia/Seoul. 해외 종가는 1일 래그 |
| 수익률 | 일별 단순수익률, KRW 기준, 환헤지 미적용이 본 결과 |
| 거래 비용 | 수수료 0.00015 + 슬리피지 0.0005 (회전율 기준, `rebalance_step`) |
| 시작 상태 | 현금 100%, NAV 1 |
| 무위험수익률 | 0 (`calculate_metrics(risk_free_rate=0.0)`) |
| 지표 | `calculate_metrics`의 12개 지표, 연 252거래일 |
| 공통 날짜 | 모든 전략·벤치마크가 같은 평가일 집합을 쓴다. 한 전략이라도 수익률을 낼 수 없는 날은 전 전략에서 제외하고 사유를 기록한다. 가격 보간은 하지 않는다 |

## 2. Walk-Forward 윈도우

rolling 4년 학습 → 1년 테스트, 1년씩 이동, 윈도우마다 완전 재학습한다
(`walk_forward_split(train_years=4, test_years=1, min_windows=2)`).

| Window | 학습 | 테스트 |
| --- | --- | --- |
| W1 | 2020-01-01 ~ 2024-01-01 | 2024-01-01 ~ 2025-01-01 |
| W2 | 2021-01-01 ~ 2025-01-01 | 2025-01-01 ~ 2026-01-01 |

- 학습 구간 마지막 1년은 검증 구간이다. 체크포인트 선택(best model)과 λ 선택은 검증 구간 성과로만 한다.
- 테스트 구간은 관측 lookback-1행만 직전 구간에서 문맥으로 빌리고, 성과는 테스트 첫날부터 계산한다.
- 정규화 scaler를 쓰는 입력이 생기면 윈도우별 학습 구간에서만 fit한다.

## 3. 비교 전략

| 전략 | 규칙 |
| --- | --- |
| PPO | 결정론적 mean action. 보상 3종(return, sharpe, mdd_penalty) |
| MVO | 최대 샤프, 252거래일 롤링 공분산, 합=1·공매도 금지·개별 최대 40%, 매월 첫 거래일 리밸런싱 |
| 동일가중 | 위험자산 동일가중, 현금 0, 매월 첫 거래일 리밸런싱, 사이에는 표류 |
| 판정 벤치마크 | 4절의 50:50 합성 지수. 거래 비용 없음 |

- **Safe-Guard(MDD 15% 초과 시 종료)**: 학습 에피소드 종료 조건으로만 쓴다. 비교 백테스트는 모든 전략을 종료 없이 끝까지 평가한다. 각 전략이 테스트 중 MDD 15%를 처음 넘긴 날짜는 별도로 보고한다.
- 동일가중·MVO도 PPO와 같은 비용·시작 상태·평가일을 쓴다.

## 4. 판정 벤치마크

KOSPI와 S&P 500(KRW 환산)을 매일 50:50으로 재조정하는 합성 지수다.

$$R^{B}_t = 0.5\,R^{KOSPI}_t + 0.5\,R^{SPX,KRW}_t$$

$$R^{SPX,KRW}_t = \frac{P^{SPX}_{u(t)} \cdot FX_t}{P^{SPX}_{u(t-1)} \cdot FX_{t-1}} - 1$$

- $t$, $t-1$은 연속한 공통 평가일, $u(t)$는 $t$ 직전 미국 세션이다. FX는 KRW per USD로, 평가 시각까지 공개된 최신 관측을 쓴다.
- 두 지수 모두 가격지수(PR)다. 배당 포함(TR) 지수는 쓰지 않으며, PPO·MVO·동일가중의 ETF 수익률도 같은 기준인지 함께 보고한다.
- FX 본 결과는 ALFRED DEXKOUS다. SMBS 매매기준율은 민감도로만 보고한다.
- 산식과 원천 검증은 #113 `benchmark_audit`의 수익률을 그대로 쓴다. 개별 KOSPI·S&P 500 지수는 참고로만 표기한다.

## 5. 성능 기준 판정

선택된 PPO(검정 1 이후 검증 구간으로 고른 보상 1종)를 벤치마크와 비교한다.

| 기준 | 판정 |
| --- | --- |
| 샤프비율 | PPO − 벤치마크 ≥ +0.2 |
| 누적 수익률 | PPO − 벤치마크 ≥ +10%p |

- 두 테스트 윈도우를 이어 붙인 2년 수익률로 판정한다. 윈도우별 값도 함께 보고한다.
- PPO 값은 seed 5개 지표의 평균이다. 기준을 넘긴 seed 수도 함께 보고한다.
- 두 기준을 모두 넘겨야 "달성"이다. 하나만 넘기면 기준별로 따로 보고한다.

| 단계 | 내용 |

## 7. ANOVA 표본과 검정

주 종속변수는 **샤프비율** 하나로 고정한다. 다른 지표는 기술통계로만 보고한다.
유의수준은 0.05다. 효과 p<0.05일 때만 Tukey HSD를 수행한다(`experiments/anova.py`).

| 검정 | 요인 | 표본 단위 | 그룹당 n |
| --- | --- | --- | --- |
| 1. 보상 3종 One-way | reward | seed × 테스트 윈도우의 테스트 구간 샤프 | 10 (5 × 2) |
| 2. 전략 One-way | PPO·MVO·동일가중 | 21거래일 블록의 블록 샤프 | 테스트 2년의 완전 블록 수 |
| 3. 전략 × 국면 Two-way | 전략, 국면 | 검정 2와 같은 블록 | 셀별 블록 수 |

- 검정 2·3의 MVO·동일가중은 결정론적이라 seed 표본이 없다. 그래서 테스트 구간을 겹치지 않는 21거래일 블록으로 나눈다. 블록은 각 윈도우의 테스트 첫날부터 시작한다. PPO의 블록 값은 선택된 보상 seed 5개의 블록 수익률을 평균한 수익률로 계산한다.
- 21거래일이 안 되는 마지막 블록은 제외한다.
- 같은 블록을 세 전략이 공유하므로 블록 간 반복측정 구조가 있다. 본 결과는 One-way이고, 이 한계를 리포트에 적는다. 블록을 요인으로 넣은 결과는 민감도로만 보고한다.
- 일별 수익률을 표본으로 쓰지 않는다.

## 8. 시장 국면

- 블록 시작 직전 60거래일의 벤치마크 복리수익률로 정한다(`experiments/regimes.py`, lookback=60, threshold=0.05).
- +5% 초과는 상승, −5% 미만은 하락, 경계 ±5%를 포함한 그 사이는 횡보다. 이력이 60거래일보다 짧으면 unknown이다.
- unknown 블록은 검정 3에서 명시적으로 제외하고 개수를 보고한다.
- 셀당 블록이 2개 미만이면 검정 3은 수행 불가로 보고한다. 블록 크기나 임계값을 바꿔 셀을 채우지 않는다.

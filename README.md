# 통합 자율 로보어드바이저

강화학습 기반 동적 자산배분 엔진과 LLM 에이전틱 투자 리서치를 결합한 설명 가능한 포트폴리오 관리 시스템.

리서치 에이전트가 탐지한 위험 이벤트를 리스크 태그로 변환해 강화학습 환경의 관측 공간과 Safe-Guard 모니터링에 반영하여,
"뉴스에서 발견된 리스크가 포트폴리오 비중 조정에 어떻게 반영되는가"를 end-to-end로 추적한다.

## 상태

초기 설정 단계. 아래 항목은 구현이 진행되면서 채워진다.

## 시스템 아키텍처

```text
데이터 수집 ─→ 누수 방지 전처리 ─→ Gymnasium 환경 ─→ PPO 학습 ─→ Walk-Forward 백테스트
                                        ↑                              ↓
                              리스크 태그 피처              MVO · 동일가중 · 벤치마크 비교
                                        ↑                              ↓
뉴스/DART 수집 ─→ ChromaDB ─→ LangGraph 리서치        SHAP 해석 · ANOVA 검증
                                                                       ↓
                                                   FastAPI 5 엔드포인트 ─→ Streamlit 6 페이지
```

> 다이어그램 이미지 버전은 구현 완료 후 교체한다.

## 실행 방법

```bash
cp .env.example .env   # API 키 입력
docker compose up
```

- API: http://localhost:8000 (Swagger UI: `/docs`)
- 대시보드: http://localhost:8501

## 확정된 설계 결정

| 항목 | 확정값 |
|---|---|
| 자산 유니버스 | 국내 ETF + 해외 ETF 혼합 (12개 목표) |
| 거래일 정합 | 국내·해외 거래일 교집합 + 해외 종가 1일 래그 |
| 기준 통화 | KRW (해외분 USD/KRW 환산), 환헤지 비교본 병행 |
| 판정 벤치마크 | KOSPI / S&P500(KRW 환산) 50:50 합성 지수 |
| 강화학습 | PPO (Stable-Baselines3), 최소 100,000 스텝 |
| 백테스트 | Walk-Forward rolling 4년 학습 → 1년 테스트, 최소 2개 윈도우 |
| `/research` 응답 | 캐시 적중은 동기 5초 이내, 신규 리서치는 비동기 job |

## 보상 함수 설계 근거

구현 후 작성. 3종(단순 수익률 / 샤프 기반 / MDD 페널티) 비교 결과와 λ 선택 근거를 기술한다.
